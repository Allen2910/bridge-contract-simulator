# Contributing / 參與貢獻

[中文](#中文) | [English](#english)

## 中文

歡迎透過 GitHub Issues 回報錯誤、操作不清楚之處及功能建議。為了讓問題容易重現，請附上：

- 完整模擬條件與合約。
- 有效樣本數與隨機種子。
- 裝置、作業系統及瀏覽器版本。
- 預期結果與實際結果。

送出程式碼變更前，請先建立 Issue 說明目的與做法。除非另有書面約定，接受的貢獻會與本專案其他原創程式碼一樣，依 PolyForm Noncommercial License 1.0.0 提供。

請勿提交沒有合法散布權的牌局資料、圖片、程式碼或其他第三方內容。

## English

GitHub Issues are welcome for bugs, unclear inputs, and feature requests. To make a report reproducible, please include:

- The complete simulation constraints and contract.
- The valid sample count and random seed.
- Device, operating system, and browser version.
- Expected and actual behavior.

Before submitting code, please open an Issue describing the purpose and proposed approach. Unless otherwise agreed in writing, accepted contributions will be made available under the PolyForm Noncommercial License 1.0.0, like the project's other original code.

Do not submit deal data, images, source code, or other third-party material that you do not have the right to distribute.
