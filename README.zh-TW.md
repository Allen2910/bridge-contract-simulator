# 橋牌合約成約率模擬器

[English](README.en.md) | [返回雙語首頁](README.md)

橋牌合約成約率模擬器是一套可安裝、可離線使用的網頁應用程式。使用者可以輸入南北家的牌型、點力、特定持牌與敵方限制，產生符合條件的牌局，再以 DDS double-dummy 最佳攻防分析指定合約的理論成約率。

## 線上使用

[開啟橋牌合約成約率模擬器](https://bridge-contract-simulator.noisyhen1.chatgpt.site)

不需要註冊帳號。發牌、條件過濾、DDS 分析及統計都在使用者的裝置上完成，牌局不會上傳到伺服器。首次載入完成後，可以將網站安裝到手機或電腦並離線使用。

## 誰適合使用這個網站？

- **固定搭檔與競賽選手**：驗證雙方對某個制度範圍、邀請叫或成局判斷的不同看法。
- **橋牌教練**：設計符合特定點力、牌型與配合條件的教材，並用大量牌局說明制度選擇。
- **叫牌制度設計者**：比較不同牌型定義、點力區間或配合條件對合約結果的影響。
- **校園及地方橋藝社**：把抽象的「通常可以成局」轉換成可以重複測試的條件與統計結果。
- **進階學習者**：研究 3NT、四線高花、滿貫等合約在不同條件下的理論表現。
- **對橋牌程式與資料分析有興趣的開發者**：了解條件式發牌、Monte Carlo 模擬與 DDS 的實際應用。

這個工具特別適合回答「如果制度所描述的牌真的長這樣，指定合約在最佳攻防下有多常能完成？」它不是叫牌老師，也不會直接判定某個叫品永遠正確。

## 主要功能

- 設定北家與南家的 HCP 範圍。
- 設定未指定花色的牌型，例如 `4333,4432,5332`。
- 依 `S-H-D-C` 設定完整或部分花色張數，例如 `5-4-2-2` 或 `5-?-?-?`。
- 指定一門或多門持牌，例如 `S=AKQJ10xxx,H=Axxxx`。
- 限制至少一門單張或缺門。
- 設定南北合計 HCP。
- 設定南北王牌配合的最少與最多張數。
- 設定東西王牌分布，例如 `3-1,2-2`。
- 限制東家與西家各自的 HCP 上限。
- 固定南北兩手牌，只隨機分配東西家的未知牌張。
- 指定合約線位、花色、莊家與隨機種子。
- 依 95% 目標誤差自動估算樣本數，或自行輸入模擬副數。
- 顯示成約率、95% Wilson 信賴區間、平均磴數及完整磴數分布。
- 顯示成約與失敗的代表牌例，包含四家 HCP、牌型及每門持牌。
- 繁體中文與英文介面切換，並記住語言選擇。

## 使用方式

1. 選擇「條件模擬」或「固定南北牌」。
2. 輸入南北家的 HCP、牌型及其他必要限制。
3. 選擇要分析的合約與莊家。
4. 選擇目標誤差，或手動輸入有效模擬副數。
5. 按下「開始模擬」，查看成約率、圖表及代表牌例。

固定手牌採用 PBN 的 `S.H.D.C` 順序。例如：

```text
AKQJ.T98.765.432
```

依序代表黑桃 `AKQJ`、紅心 `T98`、方塊 `765`、梅花 `432`。缺門可以留空，例如 `AKQJT.9876.432.`。

## 特定花色牌張

```text
S=AKQJ10xxx
S=AKQJ10xxx,H=Axxxx
```

- `S/H/D/C` 分別代表黑桃、紅心、方塊、梅花。
- `10` 和 `T` 都代表十。
- 每個 `x` 代表一張不同的非 A/K/Q/J 牌。
- 模式會限定該門總張數；`S=AKQJ10xxx` 表示正好八張黑桃。
- 沒有明確寫出的 A/K/Q/J 不會出現在該門。
- 多門限制以逗號分隔。

## 如何解讀結果

模擬次數指的是符合全部條件、且完成 DDS 分析的有效牌局數。條件越罕見，程式可能需要嘗試越多候選牌局才能找到一副有效牌。

在成約率接近 50% 的最保守情況下，95% 抽樣誤差約為：

| 有效樣本 | 約略誤差上限 |
| ---: | ---: |
| 385 | ±5.0% |
| 1,068 | ±3.0% |
| 2,401 | ±2.0% |
| 9,604 | ±1.0% |

相同條件、模擬次數及隨機種子會產生相同牌局，方便重現、討論與核對。

## 重要限制

DDS 是 double-dummy 分析：它假設四家都看得到全部手牌，而且每一步都選擇最佳打法。因此本工具顯示的是 **DDS 理論成約率**，不是人類牌桌上的實戰成約率。

結果適合用來比較條件或合約，例如比較同一組條件下的 3NT 與 4♠；不應單獨用來宣稱某項制度在真人比賽中必然有相同比例的成功率。輸入條件本身也會直接影響結果，因此分享數據時應同時公開條件、樣本數與隨機種子。

## 安裝與離線使用

- Android／Chrome：開啟網站後選擇「安裝應用程式」。
- iPhone／Safari：按下分享按鈕，選擇「加入主畫面」。
- 桌面瀏覽器：若瀏覽器支援 PWA，可使用網址列或選單中的安裝功能。

第一次開啟需要網路以下載介面與 DDS WebAssembly；快取完成後即可離線使用。

## 本機預覽

`dist/` 是可直接部署的靜態網站，不需要 Node.js 建置或後端 API。

在本專案目錄執行：

```powershell
python -m http.server 8765 --directory dist
```

然後開啟 `http://localhost:8765`。請不要直接雙擊 `index.html`，因為 Service Worker 與 JavaScript module 需要透過 HTTP 或 HTTPS 載入。

## 部署

將 `dist/` 中的檔案部署到 GitHub Pages 或其他 HTTPS 靜態網站空間即可。PWA 不需要後端伺服器。

## 問題回報與建議

公開到 GitHub 後，可以使用 repository 的 Issues 回報：

- 無法產生符合條件的牌局。
- 條件輸入或翻譯不清楚。
- 結果無法重現。
- 手機或特定瀏覽器無法執行。
- 希望增加的新條件或統計方式。

回報時請附上輸入條件、合約、樣本數、隨機種子、裝置與瀏覽器版本。
